# 實固圓盤系統支撐架產品數量表

## PDF 品項與排列（2026/11/19）

目前共 356 個品項：依《綜合版-重量計算表20221013(增新超重支撐模組).pdf》的 No.1–334 列次先排出 333 個有效品項，第 300 列無產品識別資料不虛構產品；PDF 未列的 23 個既有品項保留在後方。相同編號的不同規格分列，不以編號單獨去重。

- 編號以 PDF 明列者為準；PDF 未載的編號、規格或單重不推估。43 個對應既有品項採 PDF 編號及規格並補入空白單重，原始值保存在核對資料中。
- 不同或相似而不確定的項目以紅字保留，使用「只看紅字待核對」集中檢查，確認後可手動刪除。重新開啟不會補回已刪除的紅字；「補齊預設品項」是明確的手動恢復操作。
- 既有工程、客戶、業務、製表、數量、自訂欄位與人工單重保留。非空白單重與 PDF 不同時保留原值並標紅；後續手動編輯不會因重新整理而重設。
- 客戶名稱、工程名稱、負責業務與製表人預設空白，由使用者自行填寫，沒有預設工程或人名。
- 網頁「PDF品項核對」可查看全部334列、紅字差異、合併及待補資料，並下載CSV。另有 [完整核對報告](reports/pdf-merge.html) 和新增／重複／待補／差異CSV。
- 排列由明確的 PDF 列次決定，與舊瀏覽器儲存順序、分類或編號字母排序無關；載入舊資料也會重新排好順序。

可重建的來源資料在 `catalog/weight-pdf-20221013.json`，只包含產品列，不包含 PDF 抬頭中的客戶或工程資料。執行 `python3 scripts/build-catalog.py` 及 `python3 scripts/build-standalone.py` 會更新線上、離線單檔及 PWA 快取版本。

回歸檢查：`node tests/pdf-order.cjs`、`node tests/workbook.cjs`、`node tests/pwa.cjs`、`node tests/password.cjs`。可用 `APP_URL` 與 `CHROMIUM_PATH` 指定測試網址及瀏覽器。

依使用者提供的型錄與品號整理，使用繁體中文的靜態網頁；無伺服器、登入或 CDN 依賴。

**此版本依已確認的對話需求重建，並將來源檔與可離線使用的單檔版一起保存在 Git。**

## 使用

### 安裝到手機與離線使用（PWA）

這個版本可安裝到主畫面，不需安裝 APK 或送 App Store。安裝需要先透過 HTTPS 開啟已發布的網站。

1. 若尚未發布網站，到 [GitHub Pages 設定](https://github.com/F12321F/QuantityTable/settings/pages)，選 **Deploy from a branch → main → / (root) → Save**。
2. 等待 GitHub Pages 部署完成後，網址通常是 `https://f12321f.github.io/QuantityTable/`。本次工作區網路對該網域與 GitHub Pages API 回傳 403，未確認公開網站是否已啟用，不能以本機測試當作正式網站發布證據。
3. Android 使用 Chrome 開啟網站，按「安裝到手機」，或瀏覽器選單的「安裝應用程式／新增至主畫面」。iPhone／iPad 使用 Safari 的「分享 → 加入主畫面 → 新增」。
4. 從主畫面開啟後先連線一次，等顯示「已可離線使用」；之後可離線開啟、編輯、儲存、預覽及下載 PDF。實際列印仍使用手機／印表機支援的列印方式。
5. 新版本準備好時顯示「更新並重新開啟」，由使用者決定更新時機，不在填表途中強制重載。

資料仍保存在該裝置。Safari／Chrome 分頁與主畫面 App 不保證共用資料；既有資料可先下載備份。清除網站資料或移除相關瀏覽器儲存空間會影響本機資料。PWA 首次快取、安裝與取得更新需要連線；沒有離線前先開啟網站的裝置無法直接在斷網時首次載入。

### 共用開啟密碼（簡易防誤用）

目前 `password-config.json` 為 `enabled: false`，**尚未啟用共用密碼**，原有數量表仍可使用。先由管理者完成以下設定：

1. 開啟網站的 [密碼設定頁](password-setup.html)，在瀏覽器內輸入兩次 8–128 字元的共用密碼。
2. 按「產生並下載驗證設定檔」，取得 `password-config.json`。產生過程只在本機執行，不上傳明碼，設定檔只含隨機鹽值與 PBKDF2-SHA-256 驗證值。**產生檔案不會自動改變網站密碼。**
3. 將驗證檔交給助手套用，或由儲存庫管理者取代根目錄同名檔案，執行 `python3 scripts/build-standalone.py`，將更新的設定檔、`sw.js` 與單檔 HTML 一起提交。建置工具會拒絕明碼或額外欄位，避免誤將密碼提交到 Git。
4. 網站發布後，在 App 按「更新並重新開啟」。套用新版後，每次重新開啟或重新整理都需輸入共用密碼；也可用抬頭的「鎖定」手動上鎖。離線時使用已快取的設定驗證。

密碼錯誤、設定無法載入或格式不正確時，表單維持鎖定，不清除原有資料。單檔版會內嵌相同驗證設定。更換密碼須重做上述流程；新設定要等裝置連線並套用更新後才生效。

此功能是使用者指定的簡易開啟限制，**不等同伺服器帳號權限或資料加密**。網站程式及驗證值是公開靜態資產；既有本機資料不會加密，下載的舊版也不會被遠端撤銷。需要正式存取控制時應改用後端登入與授權。

### 單檔離線版

下載整個儲存庫後開啟 `index.html`，或使用 [單檔下載版](downloads/quantity-table.html)（在 GitHub 檔案頁按下載原始檔，再以瀏覽器開啟）。

- 抬頭左側依序是客戶名稱、工程名稱，右側依序為日期、負責業務、製表人。總重量集中顯示在產品明細下方。
- 預列 356 個品項／規格，依 PDF 列次排列，可搜尋品號、名稱、規格與分類，也可只看已填數量。
- 數量是 0–999,999 整數；單重以 kg 為單位、最多 3 位小數。單重可留白，未計重項目會提示，不將未知重量假定為 0。
- 「＋ 自訂新增品項」可建立自己的品項；每列右側固定顯示「刪除」，手機亦可直接操作。
- 「＋ 新增欄位」可新增最多 6 個文字欄位，例如備註、使用位置、批號。表格上方的「刪除欄位」可刪除欄位與內容。品項及欄位刪除後，提示提供「復原」。
- 資料自動存於此瀏覽器的 localStorage。關閉再開啟可續填；清除瀏覽器資料會移除。這不是跨裝置同步。「下載資料備份」輸出 JSON，包含舊版移除品項的備份（目前沒有匯入按鈕）。
- 「預覽 PDF」顯示真正嵌入 PDF 的各頁影像，可符合寬度／100%／150% 縮放、返回編輯或下載目前預覽。
- 「下載 PDF」直接產生 A4 多頁 PDF；每頁重複公司 Logo、客戶／工程名稱、日期／負責業務／製表人與欄名。有自訂欄位時改用橫式。
- 「列印表單」使用瀏覽器列印對話框，每頁重複客戶／工程名稱、日期／負責業務／製表人與欄名。數量 0 的品項不列入 PDF 或列印。
- 直接下載 PDF 使用本機中文字型繪製成 192 DPI 頁面影像，因此文字不可選取；瀏覽器列印存成 PDF 可保留文字。預覽及 PDF 不會上傳表單資料。

## 型錄與品號

來源為使用者上傳的實固《圓盤系統支撐架》`7527.pdf`，封底 2025/11，共 48 頁。詳細對照見 [catalog/SOURCES.md](catalog/SOURCES.md)。

- 平主架 V60、主架 V61、橫桿 H66：以長度公分補三碼，例如 V60150、V61150、H66150。
- 斜桿 D6：先橫向、後高度，以分米各補兩碼，例如 0.6 × 1.5 m → D60615。
- 定位桿依PDF列出 L61515、L61815、L62415、L61818。
- 下調 J48601、上調 U48601、活動下調 J48600S、活動上調 U48600S（以PDF為準）、標準基座 V62020、輔助桿 V62025／V62050。
- 本次依最新PDF補入缺少的品項；舊型錄的移除記錄不會拿來刪除不同ID的PDF品項。
- 工作爬梯踏板約重 48 kg；重型鋁製爬梯整組（含螺絲與扶手）16.53 kg。其餘型錄未載單重留白，不推估。
- `自編-xxx` 是表單識別碼，不是官方品號。使用者補充的編號以 `codeSource: user` 與型錄明列文字區分。

## 開發與驗證

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

開啟伺服器後執行 `node tests/workbook.cjs`。另可執行 `node tests/password.cjs` 驗證本機設定工具、密碼輸入、手動鎖定、錯誤設定、離線及單檔版；測試使用明確的測試密碼，不會啟用正式網站密碼。另可直接執行 `node tests/pwa.cjs`，它會啟動暫時伺服器，驗證專案子目錄、快取、關閉後離線重開、資料保存、PDF 匯出及更新流程。測試需 Playwright 與 Chromium；本雲端基礎環境已提供，可用 `CHROMIUM_PATH` 指定 Chromium，或以 `APP_URL` 指定測試網址。

重新整理型錄資料、產生單檔版：

```sh
python3 scripts/build-catalog.py
python3 scripts/build-standalone.py
```

`build-standalone.py` 會先呼叫 `build-pwa.py`，依實際 runtime 檔案內容生成 `sw.js` 的快取版本。每次修改網頁、程式、樣式或圖示，都應重新執行再提交 `sw.js`。安裝設定是 `manifest.webmanifest`，手機圖示位於 `assets/pwa/`。

單檔版會移除 PWA 安裝入口與 service worker 註冊，繼續保持一個 HTML 即可離線使用；主畫面安裝請使用 HTTPS 網站版。單檔版會儲存為 `downloads/quantity-table.html`。加上 `--output /指定目錄`，另輸出中文檔名 HTML 與來源 ZIP。請將修改過的來源與重新產生的單檔版一起提交。

## GitHub Pages

此專案可直接作為靜態網站。若要啟用，至儲存庫 **Settings → Pages → Deploy from a branch**，選擇 `main` 分支及 `/ (root)`。提交 PWA 程式碼不等於已啟用或驗證 Pages 網站；本地端已驗證功能，正式網址尚待使用者在設定啟用或確認。
