設定共用開啟密碼

在這個頁面輸入你要共用的密碼。密碼只在此瀏覽器內計算，不會傳送給助手或上傳網站。

下載後如何啟用？

  1. 妥善記住密碼，提供給需要使用表單的人。
  2. 將下載的 password-config.json 傳給助手套用，或由儲存庫管理者取代 GitHub 根目錄同名檔案，重新產生單檔版與離線快取後提交。
  3. 等待網站更新，在 App 按「更新並重新開啟」，測試開啟時會要求密碼。

產生檔案不會自動啟用網站密碼。設定檔內含隨機鹽值與密碼衍生的驗證值，不含明碼；請勿在對話中提供你的密碼。

這是簡易防誤用限制，不會加密既有表單資料。共用密碼變更須更新網站；已下載的舊版或離線裝置不會立即套用新設定。
